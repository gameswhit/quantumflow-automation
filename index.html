ai-design.sh
# Let AI design the workflow
$ qflow ask "When a Stripe payment fails,
  retry 3 times, then email the customer
  and alert the billing team on Slack"

→ AI designed 6-step workflow:
  1. stripe.payment_intent.retrieve
  2. retry(3, backoff=exponential)
  3. branch: if still failed
  4. sendgrid.mail.send(customer)
  5. slack.chat.postMessage(#billing)
  6. log: mixpanel.track

# Deploy the AI-designed workflow
$ qflow deploy --approve
✓ 6 steps deployed · webhook ready

FAQ

Common questions

How is QuantumFlow different from Zapier or n8n?

Zapier is point-and-click. n8n is self-hosted visual builder. QuantumFlow adds an AI designer (describe in English → executable workflow), MiMo-powered optimization, custom code nodes with full dependency support, and sub-second execution with warm pools.

What happens if a step fails?

Configurable retries with exponential backoff, dead-letter queues, and human-in-the-loop approval gates. Every failure is logged with full context for debugging.

Can I use my own code in workflows?

Yes. Custom code nodes support Python, JavaScript, and shell scripts with full npm/pip dependency resolution in isolated sandboxes.

How does QuantumFlow relate to NebulaCraft and PulsarOps?

QuantumFlow orchestrates business workflows. NebulaCraft writes the code. PulsarOps runs it in production. Together they form a complete AI-native development and operations stack — all built on MiMo-Series models.

Is my data secure?

All data encrypted in transit (TLS 1.3) and at rest (AES-256). Per-workflow secret vault. SOC 2 Type II certified. Multi-region deployment for data residency requirements.
